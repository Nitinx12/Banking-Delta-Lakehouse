1. OVERVIEW & PURPOSE
-------------------------------------------------------------------------------
The `reports` directory contains an automated, data-driven PDF reporting engine 
for the Banking Delta Lakehouse data pipeline.

When a pipeline run completes, an Airflow alert triggers, or a weekly digest is 
scheduled, the report engine executes the following workflow:
1. Queries the PostgreSQL `audit` schema for pipeline execution metrics.
2. Evaluates run severity, SLA targets, and Data Quality (DQ) pass rates.
3. Generates high-resolution vector charts using Matplotlib.
4. Renders Jinja2 LaTeX templates with run metadata.
5. Compiles the documents via `latexmk` / TeX engine into clean PDF reports 
   (`report.pdf`, `incident.pdf`, `weekly.pdf`).
6. Attaches the generated PDF to Airflow's automated summary notification email.

3. HOW THE REPORT ENGINE WORKS (END-TO-END FLOW)
-------------------------------------------------------------------------------
1. DATA COLLECTION (`collect.py`):
   Connects to PostgreSQL in read-only mode, queries `audit.pipeline_runs`, 
   `audit.table_runs`, and `audit.dq_validations`, then serializes the result to 
   `data/context.json`.

2. EVALUATION & METRICS (`severity.py`, `kpis.py`, `flow.py`):
   Parses `context.json` against targets in `config/slo.yaml`. It determines the 
   overall run status (SUCCESS, WARNING, CRITICAL, or UNKNOWN), computes row count 
   diffs, calculates execution durations, and structures the pipeline flow diagram.

3. CHART GENERATION (`charts.py`):
   Reads the calculated metrics and uses Matplotlib to generate vector PDF 
   charts into `reports/figures/` (e.g. data volumes, DQ check heatmaps, timeline).

4. TEMPLATE RENDERING (`render.py`):
   Passes the evaluated context into Jinja2 to render LaTeX templates from 
   `reports/chapters/` into LaTeX `.tex` files in `reports/build/`. All dynamic text 
   is strictly escaped to adhere to LaTeX rules.

5. LATEX COMPILATION (`compile.py`):
   Calls `latexmk` on `main.tex`, linking the generated TeX chapters and vector 
   charts into the final output PDFs in `reports/output/`.


4. AVAILABLE MAKE COMMANDS
-------------------------------------------------------------------------------
- `make report-fixture`  : Render all test fixtures to TeX (no TeX installation required).
- `make report-pdf`      : Render and compile all test fixtures to PDF files.
- `make report-tex`      : Compile report TeX and perform log and page budget checks.
- `make report-docker`   : Run full TeX compilation inside Docker environment.
- `make report`          : Generate a daily report from live database connection.
- `make report-incident` : Generate a focused incident report (usage: `make report-incident RUN=<run_id>`).
- `make report-weekly`   : Generate a 7-day weekly digest report.
