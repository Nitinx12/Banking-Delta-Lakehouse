# Banking Delta Lakehouse - Airflow Orchestration & Reports Fix Summary

## Why We Fixed These Issues (Focus: Airflow + Reports)

The pipeline ran but had three critical issues that prevented full operational readiness:

### 1. **Airflow Pipeline Report Generation Failure**
- **Symptom**: `build_report` task failed with `up_for_retry` status, no PDF attached to summary emails
- **Root Cause**: `commands.py:report_command()` returned `python -m reports.scripts.build ...` but `banking_cmd()` already prepends the Python interpreter path, producing: `exec "/opt/banking-venv/bin/python" python -m reports.scripts.build ...` which fails (Python can't open file 'python')
- **Impact**: Daily reports never generated, emails sent without attachments, incident reports missing

### 2. **False FAILED Email Status**
- **Symptom**: Emails showed `[FAILED] Banking-Delta daily pipeline` even when all tasks succeeded
- **Root Cause**: `summary.py:decide_status()` checked `task_states.get(task_id, "")` - missing keys returned `""` which is in `PENDING_STATES`, triggering false FAILED
- **Impact**: Alert fatigue, operators ignored real failures, no trust in monitoring

### 3. **Report Attachments Missing from Emails**
- **Symptom**: Emails sent but no PDF or LaTeX source attachments
- **Root Causes**:
  - `summary.py:_find_report_attachments()` used different run_key sanitization than `paths.py:run_key()` (per-char replace vs regex collapse)
  - `send_pipeline_summary` runs in **scheduler** container but report files written to **worker**'s `report_output` volume - scheduler couldn't see the files
  - `notify.py:build_message()` hardcoded `subtype="pdf"` for all attachments, failing on `.tex` files

## Reports Folder - Complete Script Inventory

### `reports/scripts/`
| File | Purpose |
|------|---------|
| `build.py` | **Main entry point** - `python -m reports.scripts.build --kind daily|incident|weekly --dag-id X --dag-run-id Y`. Loads context via `collect.py`, evaluates severity via `severity.py`, renders LaTeX via `render.py`, draws charts via `charts.py`, compiles PDF via `compile.py`. **FIXED**: Copies rendered `.tex` files to run directory for email attachment. |
| `collect.py` | **Audit data collector** - Read-only queries against `audit.*` tables to build context dict: `run` (pipeline status), `steps` (13 pipeline steps with state/duration), `tables` (per-table row counts/watermarks), `dq` (latest DQ results per script), `errors` (classified errors), `freshness` (raw table age vs SLO window), `trends` (last N runs: duration, rows, failures). Sections degrade independently - one failure doesn't block the report. |
| `severity.py` | **Rule engine R001-R017** - Evaluates collected context into events + verdict. Rules: R001 failed run (CRITICAL), R002 partial run (MAJOR), R003 DQ suite fail (MAJOR), R004 publish mismatch (MAJOR), R005 final attempt error (MAJOR), R006 concurrency resolved (MINOR), R007 retried tables (MINOR), R008 DQ warning (MINOR), R009 volume deviation (MINOR), R010 zero-row full load (MAJOR), R011 duration regression (MINOR), R012 freshness breach (MAJOR/MINOR), R013 schema drift (MAJOR), R014 watchdog MISSED/STUCK (MAJOR), R015 watchdog error (CRITICAL), R016 degraded sections (MINOR), R017 skipped tables (INFO). Verdict = max severity; labels: INFO=HEALTHY, MINOR=ATTENTION, MAJOR=ACTION REQUIRED, CRITICAL=INCIDENT. |
| `render.py` | **LaTeX-safe Jinja2 environment** - Custom delimiters (`\BLOCK{}`, `\VAR{}`, `\#{}`), auto-escapes LaTeX special chars (`\`, `&`, `%`, `$`, `#`, `_`, `{`, `}`, `~`, `^`). Filters: `fmt_int` (thousands separators), `fmt_pct`, `fmt_dur` (human duration), `fmt_ts`, `state_colour`, `severity_colour`, `status_colour`, `plural`, `raw` (pass-through), `ident` (breakable identifiers), `breakable` (break at punctuation). |
| `paths.py` | **Path management** - `run_key()` sanitizes dag_run_id to filesystem-safe key (regex `[^A-Za-z0-9_]+` → `_`). `output_root()` from `REPORT_OUTPUT_DIR` env or `reports/output`. `run_dir()`, `pdf_path()`, `latest_pdf()`, `context_path()`, `fixture_paths()`, `fixture_path()`, `retention_days()`, `load_report_config()`, `load_slo_config()`, `prune_runs()` (deletes runs older than 30 days). **FIXED**: `run_key()` regex matches `summary.py` usage. |
| `compile.py` | **latexmk wrapper** - Runs `latexmk -r latexmkrc -jobname=X main.tex` in `REPORTS_DIR` with `SOURCE_DATE_EPOCH` for reproducible builds. Output to `build/`, aux to `build/aux/`. Cleans job state before each run (handles Windows file locks). Parses page count from log. Redacts secrets from log via `audit._redact()`. |
| `charts.py` | **Matplotlib charts** - Shared style (Inter font, palette per layer). Figures: `task_timeline` (horizontal bars), `volumes_dumbbell` (today vs median rows), `layer_rows` (bar per layer), `dq_heatmap` (check×layer matrix), `freshness_bullet` (age vs window), `error_categories` (horizontal bars), `trend_duration` (line + median), `trend_failures` (3-panel small multiples), `publish_reconcile` (source vs landed rows). `figure_include()` saves PDF and returns `\includegraphics` command. |
| `flow.py`` | **TikZ flow diagram** - Builds nodes/edges from steps list. Extracts (mongo/databricks/mysql) stacked left at x=0; chain (preflight → raw_tests → staging_load → staging_tests → analytics_load → analytics_tests → marts_load → marts_tests → publish → finalize_audit) at x=1. Returns dict with nodes (id, layer, state, x, y, label, duration) and edges (src→dst). |
| `severity.py` | (See above) |

## What Was Fixed (Files Modified)

### Airflow Fixes
1. **`airflow/include/banking_airflow/commands.py:63-68`** - `report_command()` returns `-m reports.scripts.build --kind {kind} ...` (removed `python` prefix)
2. **`airflow/include/banking_airflow/summary.py:117-131`** - `decide_status()` only checks PENDING_STATES for tasks with actual state (not default `""`)
3. **`airflow/include/banking_airflow/summary.py:311-345`** - `_find_report_attachments()` uses same regex as `paths.run_key()`; includes `.tex` files
4. **`airflow/docker-compose.yml`** - Added `report_output:/opt/banking/reports/output` volume mount to `airflow-scheduler` and `airflow-apiserver` so they can read report files
5. **`airflow/include/banking_airflow/notify.py:77-96`** - `build_message()` detects MIME type: `.tex` → `application/x-tex`, `.pdf` → `application/pdf`

### Reports Fixes
6. **`reports/scripts/build.py:279-319`** - `_build_kind()` copies all `.tex` files from `BUILD_DIR` to run directory after render (both normal and degraded builds)
